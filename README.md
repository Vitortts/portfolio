#  Portfólio Pessoal

## Objetivo do Projeto

Este projeto é meu portfólio pessoal, desenvolvido a partir de um design estático criado no Figma. O objetivo inicial foi construir a versão desktop com fidelidade ao layout planejado, e posteriormente evoluir o projeto aplicando media queries para garantir responsividade completa em dispositivos mobile, à medida que aprofundei meus estudos sobre o tema.

## Tecnologias Utilizadas

- **HTML5** — estruturação semântica do conteúdo
- **CSS3** — estilização da interface
  - **Media Queries** — adaptação do layout desktop para versão responsiva mobile

## O Que Foi Aprendido

O desenvolvimento começou com foco total na versão desktop, seguindo rigorosamente o design estático do Figma. Após consolidar essa etapa, aprofundei meus estudos sobre media queries e apliquei esse conhecimento para adaptar o layout original a telas menores — um processo que exigiu revisitar decisões de espaçamento, hierarquia visual e organização de elementos que haviam sido pensados originalmente apenas para desktop.

Esse processo reforçou a diferença prática entre desenvolver mobile-first e adaptar um layout desktop-first para mobile posteriormente, e me deu uma base sólida sobre os desafios reais de retrofitar responsividade em um projeto já estruturado.
